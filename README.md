# 英単語学習アプリ

ブラウザだけで動作するシンプルな英単語学習ページです。Python を実行できない環境でも利用できます。

## 使い方

### ブラウザで直接開く方法

1. 本リポジトリをダウンロード（または ZIP を展開）します。
2. `webapp/static/index.html` をブラウザで開きます。

これだけで単語学習ページが表示されます。**意味を表示**ボタンで日本語訳を確認し、**次の単語**ボタンで別の単語を表示できます。

### Python サーバーを使う方法（任意）

Python 3 が利用できる場合は、以下のサーバーを起動してアクセスすることもできます。

```bash
python3 webapp/app.py
```

その後、ブラウザで `http://localhost:8000` を開きます。
