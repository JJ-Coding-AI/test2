# 日英単語帳アプリ

日本語の単語を表示し、英語での意味を確認できるシンプルな単語帳アプリです。

## 使い方

### サーバーを利用する場合
1. Python 3 を用意します。
2. リポジトリのルートで以下を実行します。

```bash
python3 webapp/app.py
```

3. ブラウザで `http://localhost:8000` を開きます。

### ファイルを直接開く場合
`webapp/static/index.html` をブラウザで開くだけでも利用できます。

## 操作方法
- **次の単語** で新しい単語を表示
- **前の単語** で履歴をさかのぼる
- **意味を表示** で英語の意味を表示
